# bio-amazonia-ia
# 🌳 Bio Amazonía IA

Este proyecto es un sistema de visión artificial diseñado para identificar 5 especies críticas de la Amazonía.

## 🚀 Características
* **Modelo:** Transfer Learning con MobileNetV2.
* **Dataset:** Imágenes curadas mediante búsqueda automatizada y validación.
* **Interfaz:** Aplicación web interactiva creada con Streamlit.

## 🐾 Especies Soportadas
1. Paiche (`Arapaima gigas`)
2. Gamitana (`Colossoma macropomum`)
3. Guacamayo Rojo (`Ara macao`)
4. Shihuahuaco (`Dipteryx micrantha`)
5. Mono Choro (`Lagothrix lagotricha`)

## 🛠️ Instalación
1. Clona el repositorio.
2. Instala las dependencias: `pip install -r requirements.txt`.
3. Ejecuta la app: `streamlit run app_amazonia.py`.
